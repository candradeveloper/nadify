## ✨ Fitur Nadify

- 🎵 **Streaming musik** dari YouTube Music tanpa login
- 🎤 **Lirik karaoke real-time** — sinkron dengan lagu, baris aktif highlight
- 🌙 **Dark & Light mode** — mengikuti sistem atau pilihan manual
- 🎨 **Tema ungu eksklusif** — brand warna Nadify
- 📱 **UI modern** — desain bersih, smooth, responsif
- 📶 **Offline** — download lagu untuk diputar tanpa internet
- 🔊 **Audio equalizer** bawaan
- 🎙️ **Music recognition** — kenali lagu yang sedang diputar
- 🔀 **Queue & shuffle** — kelola antrian lagu dengan mudah
- 📊 **Statistik** — lihat histori dan lagu favorit kamu

## 📥 Download

Unduh APK terbaru dari [Releases](https://github.com/nacdev/Nadify/releases)
atau dari [GitHub Actions](https://github.com/nacdev/Nadify/actions) (build terbaru).

## 🔧 Build Sendiri

```bash
git clone https://github.com/nacdev/Nadify.git
cd Nadify
./gradlew assembleFossRelease
```

> Butuh JDK 21 dan Android SDK.
